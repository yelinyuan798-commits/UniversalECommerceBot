首次接入
  1. 默认客服不用填商品资料。选择“按商品定制”时，先保存商品资料，并确保商品 ID 与平台一致。
  2. 在下面的配置中启用目标平台。闲鱼凭据保存在本机 config/.env。
  3. 网页接入平台需填写真实聊天页的元素选择器与标识属性；公共模板留空，保存过的本机配置会保留。
  4. 先点“开始观察”检查新消息和回复，再点“停止”。将目标平台 dry_run 改为 false，保存接入配置后，再点“开启自动回复”。登录、验证操作在弹出的独立浏览器完成。

此版本不控制手机原生 App。模拟测试通过不代表你的店铺已经通过真实收发验收。
