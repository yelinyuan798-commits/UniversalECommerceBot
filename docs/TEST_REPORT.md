## 本地自动测试

验证环境：macOS ARM64、Python 3.13、Playwright / Chromium。

**本轮完整回归：147 项测试、152 个子测试全部通过，用时 39.30 秒。**

本轮七个平台适配器导入检查、JavaScript 语法检查和 Git 差异格式检查通过。无商品配置时启用内置默认客服；平台仍保持未登录、未启用状态，需要商家完成连接后才能收发。

测试有 1 条 Starlette 关于 `httpx` 测试客户端的弃用提醒，不影响本轮通过结果。`pytest.ini` 将测试限定在 `tests/`，并配置项目导入路径，避免发布导出目录中的副本被重复收集。

覆盖内容包括：

- 七平台配置目录、显示名称与别名校验。
- 六个网页适配器在本地页面的收发集成，以及闲鱼封包/API 的受控测试。
- 客服引擎、SQLite 状态、消息防重、跨平台商品资料隔离、报价下限与禁止议价。
- 模型失败及恶意输出的处理、人工接管与恢复、观察转自动回复不补发旧消息。
- 本机工作台访问限制、配置保存、试聊、平台模式保护及独立连接的启动和关闭。

复现命令：

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python -m pytest -q
.venv/bin/python main.py doctor
.venv/bin/python -m compileall -q core platforms web main.py
git diff --check
```

CI 配置为 Python 3.11 / 3.13。远端 CI 是否通过需查看对应提交的运行记录，不能从本机结果推断。

## 默认客服与模式切换（2026-11-04）

- 新安装不读取示例笔记本，使用空商品资料的默认客服；不需要商品 ID 或 AI 密钥。
- 旧配置没有 `reply_mode` 时继续按商品回复；切换模式、重启后保留商品资料、去重记录和人工暂停状态。
- 默认模式不引用保留的商品价格，也不调用模型；付款、改订单、退款、投诉和具体商品问题进入人工待办。
- 运行中禁止切换或保存设置；API 不缓存私有状态，静态文件要求重新验证，避免升级后混用旧脚本。
- 本地浏览器实操通过：默认问候与询价、退款后暂停、保存演示商品后报价、切回默认不泄漏商品价格、刷新后恢复定制资料。
- 独立的隔离浏览器验证通过：旧模式迟到的回复或错误不会显示到新模式会话。

上述新增功能在本地测试，不代表本轮重新完成了真实店铺联调。
