## 本地自动测试

验证环境：macOS ARM64、Python 3.13、Playwright / Chromium。

**本轮完整回归：174 项测试、216 个子测试全部通过，用时 26.59 秒。**

本轮七个平台适配器导入检查、JavaScript 语法检查和 Git 差异格式检查通过。无商品配置时启用内置默认客服；平台仍保持未登录、未启用状态，需要商家完成连接后才能收发。

测试有 1 条 Starlette 关于 `httpx` 测试客户端的弃用提醒，不影响本轮通过结果。`pytest.ini` 将测试限定在 `tests/`，并配置项目导入路径，避免发布导出目录中的副本被重复收集。

覆盖内容包括：

- 七平台配置目录、显示名称与别名校验。
- 六个网页适配器在本地页面的收发集成，以及闲鱼封包/API 的受控测试。
- 客服引擎、SQLite 状态、消息防重、跨平台商品资料隔离、报价下限与禁止议价。
- 模型失败及恶意输出的处理、人工接管与恢复、观察转自动回复不补发旧消息。
- 本机工作台访问限制、配置保存、试聊、平台模式保护及独立连接的启动和关闭。

复现命令：


## 默认客服与模式切换（2026-11-04）

- 新安装不读取示例笔记本，使用空商品资料的默认客服；不需要商品 ID 或 AI 密钥。
- 旧配置没有 `reply_mode` 时继续按商品回复；切换模式、重启后保留商品资料、去重记录和人工暂停状态。
- 默认模式不引用保留的商品价格；未配置 AI 时直接使用内置话术。付款、改订单、退款、投诉和具体商品问题进入人工待办。
- 运行中禁止切换或保存设置；API 不缓存私有状态，静态文件要求重新验证，避免升级后混用旧脚本。
- 本地浏览器实操通过：默认问候与询价、退款后暂停、保存演示商品后报价、切回默认不泄漏商品价格、刷新后恢复定制资料。
- 独立的隔离浏览器验证通过：旧模式迟到的回复或错误不会显示到新模式会话。

上述新增功能在本地测试，不代表本轮重新完成了真实店铺联调。

## 默认客服可选 AI（2026-11-04）

- 普通问候、感谢、询价、议价、发货和库存咨询可使用模型生成自然措辞，不只是选择固定模板；未配置或关闭 AI 时仍使用原有话术。
- 超时、HTTP 错误、异常、空输出及未通过检查的内容回退内置话术。输出检查覆盖常见虚构金额、库存、包邮、履约承诺和指令注入，但不是对任意模型文本的语义保证。
- 默认模式只发送本次买家消息和通用接待规则，不发送保留商品、自定义要求或旧聊天历史。模型返回的异常详情不会出现在买家回复或事件记录中。
- 人工接管先于模型调用；生成期间接管会抑制迟到的回复，任务取消会保留失败状态，重复消息不会重复调用模型。
- 使用实际安装的 OpenAI SDK 连接本地受控 HTTP 端点，两项集成测试通过：自然文案实际采用并标记 `ai`；503 错误回退并标记 `builtin`。没有调用真实模型服务。
- 浏览器实操通过：未配置 AI 正常接待；隔离工作台中显示真实接口链路产生的 AI 问候与询价、服务故障后内置话术回退、退款转人工后暂停。工作台区分未配置、已启用和已关闭，并按每条试聊的实际来源显示标签。

本机没有真实 AI 密钥，本轮未验证具体服务商的可用性、收费或生成质量，也没有发送真实买家消息。配置方法见[可选 AI 设置](PLATFORM_SETUP.md#可选让默认客服说得更自然)。
